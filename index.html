MAGIC STEP— Footstep Power Generation System

An electro-mechanical prototype investigating the conversion of human footstep pressure into conditioned electrical energy using a 2×3 matrix of piezoelectric transducers. Features a springless direct-flexure platform (300 × 160 × 10 mm), full-wave rectification, ESP32 embedded telemetry, and a 1S2P lithium-ion storage testbed.

SEC 02

The Challenge & Harvesting Opportunity

During our engineering capstone at Sanjivani University Makerspace, our team set out to capture a fraction of the mechanical kinetic energy dissipated daily on high-traffic university walkways, corridors, and stairs.

We evaluated multiple kinetic energy harvesting methodologies — electromagnetic dynamos with gear-trains, triboelectric nanogenerators (TENG), and piezoelectric ceramics. We selected a direct-transduction piezoelectric platform utilizing six ⌀27 mm Lead Zirconate Titanate (PZT) ceramic elements embedded beneath a 300 × 160 × 10 mm wooden platform without coil springs, ensuring maximum compressive strain transfer directly into electrical charge pulses.

Kinetic Energy Harvesting Technologies Compared
Transduction Approach Potential Advantages Limitations & Mechanical Considerations
Electromagnetic Dynamo (Rack & Pinion) High continuous power output; established rotary generator technology. Requires mechanical gear-trains, rack-and-pinion linkages; high mechanical wear; noisy operation and large vertical floor clearance required.
Triboelectric Nanogenerator (TENG) Extremely high open-circuit voltages (>100 V); lightweight material layers. Extremely low current (micro-amperes); delicate contact-separation surface wear; performance deteriorates under ambient humidity and dust.
Photovoltaic / Solar Tile High power density during peak daytime sunlight. Ineffective indoors, at night, or in covered staircases; vulnerable to surface scratching and dirt accumulation.
Magic Step (Piezoelectric Matrix) Solid-state electromechanical transduction; ultra-slim profile (18 mm); springless direct flexure; no moving gears; highly responsive to foot pressure. High electrical impedance; generates short transient AC spikes requiring full-wave rectification and capacitive smoothing before storage. Measured power pending.

The Engineering Question We Are Investigating

Can an array of six PZT piezoelectric discs embedded within a compact 300 × 160 × 10 mm footstep tile reliably generate sufficient electrical charge to buffer an energy storage cell, while an ESP32 provides real-time telemetry of step activity and battery condition?

Project Scope & Testing Integrity

Magic Step is built to engineering lab standards. In strict accordance with university guidelines, no test voltages, power outputs, or battery percentages are invented. The hardware is physically assembled, the ESP32 telemetry logic is operational, and scientific measurements are being logged under defined test conditions.

SEC 03

Working Principle & Energy Flow

When a person steps on the Magic Step platform, mechanical force compresses the piezoelectric ceramic elements. Through the direct piezoelectric effect, the mechanical strain displaces positive and negative ions in the crystal lattice, generating an alternating voltage spike. Because footfalls involve both impact (compression) and release (expansion), the transducer generates bidirectional AC pulses.

A full-wave diode bridge rectifier (DB107) converts these alternating pulses into unidirectional DC. A 10 µF capacitor buffers the high-impedance transient spikes, accumulating charge. This charge is routed to a lithium-ion management stage, while an ESP32 microcontroller samples scaled analog voltages to count steps and monitor the 1S2P battery pack on a 16×2 I²C LCD.

Electrical Safety & Isolation Protocol: Piezoelectric discs generate high instantaneous open-circuit voltages (>30 V) with very high source impedance. Never connect raw piezo outputs directly to ESP32 GPIO pins or lithium-ion cells without rectification, capacitive buffering, and resistive voltage division.

    Springless Mechanical Rationale

    The Magic Step design deliberately omits helical coil springs. Conventional spring designs absorb mechanical energy into spring deflection and introduce damping losses. Our direct-flexure platform uses compliant neoprene damper pads above each disc, transferring the user's kinetic energy directly into piezoelectric crystal strain while protecting the ceramic from destructive point impact.

    Firmware: MagicStep_Telemetry_ESP32.ino (C++ / Arduino IDE) 
    /*
 * MAGIC STEP — Footstep Power Generation Telemetry Firmware
 * Group 16 · Department of Mechanical Engineering · Sanjivani University
 * Platform: ESP32 DevKit V1 | Display: 16x2 I2C LCD (0x27)
 */

#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// Pin Definitions
#define PIN_PIEZO_ADC   34  // Analog pulse sense (ADC1_CH6)
#define PIN_BATTERY_ADC 35  // Battery divider sense (ADC1_CH7)
#define PIN_CHRG_STAT   32  // Charger IC status pin (Active LOW)

// Calibration Constants
const int PIEZO_THRESHOLD = 450;        // ADC threshold for step registration
const unsigned long DEBOUNCE_MS = 220;  // Minimum ms between consecutive steps
const float VREF = 3.30;                // ESP32 calibrated ADC reference
const float BATTERY_DIVIDER_RATIO = 2.0;// (R1 + R2) / R2 for 100k/100k divider

// Telemetry State
volatile unsigned long stepCount = 0;
unsigned long lastStepTime = 0;
float batteryVoltage = 0.0;
bool isCharging = false;
bool pulseDetected = false;

LiquidCrystal_I2C lcd(0x27, 16, 2);

void setup() {
  Serial.begin(115200);
  Wire.begin(21, 22); // SDA = GPIO 21, SCL = GPIO 22

  lcd.init();
  lcd.backlight();
  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print("  MAGIC STEP  ");
  lcd.setCursor(0, 1);
  lcd.print("Group 16 SU 26-27");
  delay(1800);
  lcd.clear();

  pinMode(PIN_CHRG_STAT, INPUT_PULLUP);
  analogReadResolution(12); // 12-bit ADC (0-4095)
}

void loop() {
  unsigned long currentMillis = millis();

  // 1. Read Rectified Piezo Voltage Pulse
  int piezoRaw = analogRead(PIN_PIEZO_ADC);
  if (piezoRaw > PIEZO_THRESHOLD && (currentMillis - lastStepTime > DEBOUNCE_MS)) {
    stepCount++;
    lastStepTime = currentMillis;
    pulseDetected = true;
    Serial.printf("[STEP] Count: %lu | Raw ADC: %d\\n", stepCount, piezoRaw);
  } else {
    pulseDetected = false;
  }

  // 2. Read Battery Voltage (every 500 ms)
  static unsigned long lastBatteryRead = 0;
  if (currentMillis - lastBatteryRead > 500) {
    lastBatteryRead = currentMillis;
    int batRaw = analogRead(PIN_BATTERY_ADC);
    batteryVoltage = (batRaw / 4095.0) * VREF * BATTERY_DIVIDER_RATIO;
    isCharging = (digitalRead(PIN_CHRG_STAT) == LOW);
  }

  // 3. Update 16x2 I2C Display
  static unsigned long lastLcdUpdate = 0;
  if (currentMillis - lastLcdUpdate > 150) {
    lastLcdUpdate = currentMillis;
    
    // Row 0: Step Counter and Live Pulse Indicator
    lcd.setCursor(0, 0);
    lcd.print("STEPS: ");
    char stepStr[8];
    sprintf(stepStr, "%-5lu", stepCount);
    lcd.print(stepStr);
    lcd.setCursor(14, 0);
    lcd.print(pulseDetected ? "[*]" : "   ");

    // Row 1: Battery Voltage & Charge State
    lcd.setCursor(0, 1);
    lcd.print("BAT: ");
    lcd.print(batteryVoltage, 2);
    lcd.print("V ");
    lcd.setCursor(11, 1);
    lcd.print(isCharging ? "CHRG" : "IDLE");
  }
}

    Telemetry Logic Rule

    Raw spikes over 450 ADC counts trigger a step increment with a 220 ms debounce window. When buffer voltage exceeds 4.5 V, trickle charging engages.

MAGIC STEP PROJECT WEBSITE
==========================

FILES
- index.html : Complete responsive project documentation website.

HOW TO OPEN
1. Extract the ZIP file (if you received the ZIP).
2. Open the folder named magic_step_website.
3. Double-click index.html. It will open in your web browser.
4. The website works offline; it does not require an internet connection.

HOW TO EDIT
1. Right-click index.html and open it with Notepad or Visual Studio Code.
2. Search for the text you want to change and edit it.
3. Save the file and refresh the browser.
4. Replace the gallery placeholders with your own photos. Put the photo in the same folder and use an image tag as shown in the Gallery section.

HOW TO SAVE AS PDF
Open index.html in Chrome, press Ctrl+P, choose "Save as PDF", and save.

HOW TO PUBLISH LATER
You can publish this static website using GitHub Pages. Create a repository, upload index.html (and your image files), then enable Pages in the repository settings. The exact GitHub interface can change, so follow the current GitHub Pages instructions shown in GitHub.

IMPORTANT CONTENT NOTES
- Confirm the final circuit, charger module, battery protection arrangement, exact LCD address and ESP32 pin map before presenting them as final.
- A two-cell parallel lithium-ion pack is a 1S2P arrangement. Use an appropriate charger and protection circuit.
- Do not add invented voltage, current, power, energy, battery percentage or test results. Fill the testing table with actual measured values and measurement conditions.
- The website labels unverified design and electronics details as items to confirm.
